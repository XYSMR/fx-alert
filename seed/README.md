# seed/：一次性回補的公開資料

## `mega_daily_close.csv`

兆豐銀行每個營業日的**現金賣出**收盤價，給「出國換匯計畫」判斷近 30 天第幾低用（`src/fx_alert/daily.py`）。

- **來源**：兆豐銀行網站 匯率查詢 → 歷史匯率
  <https://www.megabank.com.tw/personal/savings/foreign-service/forex>
  - 查詢項目：現金；查詢類別：營業日最後一次匯率（約 16:00）
  - 查詢區間：自訂 2025-11-17 ～ 2026-11-16（網站限制單次最多一年）
  - 用頁面上的「下載」按鈕取得（`.ods`），每種幣別一次查詢、一次下載，共 18 種
- **取得日期**：2026-11-16（台灣時間約 18:30）
- **內容**：`date` + 18 個幣別欄位（順序同兆豐牌告），每個幣別 243 個營業日，日期由新到舊。
  只取「現金銀行賣出」一欄；價格是牌告原本的 4 位小數。南非幣、瑞典幣只有即期匯率，不在這裡。
- **SHA-256**：`9f20a862d5c8c3c07c254c17b5aba3aaa3f27667745cedd05c9a961bdc17b37e`
  （下載後在瀏覽器裡算的；`tests/test_daily.py` 會檢查，檔案被改過測試就會失敗）

這份檔案不會再更新：2026-11-17 起的收盤價由我們自己記錄的牌告算出（見 README〈資料來源〉）。
網站上的匯率資料僅供參考，實際以兆豐銀行公告為準。
